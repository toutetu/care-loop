各職員が音声で入力した記録の handover_note を集約して生成しています。

未記録の方を先頭に置きます。職員が知りたいのは「誰がまだ終わっていないか」だけです。記録済みの一覧は下にたたみます。

  • 1タップで記録画面へ。間に確認画面を挟みません
  • 各行の高さは 64px。手袋をしたままでも押し間違えません
  • リスクの高い方には赤いバッジを出し、記録時に注意が向くようにします

「お迎え時に口頭でお伝えすること」（F-20）を最上部に置きます。AIが requires_verbal_contact を立てた事項が、送迎担当者のタスクとして自動で並びます。「お伝えしました」を押すと誰が・いつ・どなたに・何を伝えたかが記録されます。未完了のまま日をまたぐと管理者へ通知されます。

連絡帳に書いてあるから伝えた、にはしません。文書にも記載したうえで、口頭連絡の実行までをシステムで追跡します。介護保険制度上、事故・ヒヤリハットにはご家族への報告義務があります。

iOS標準キーボードの音声入力を使います。アプリ側で音声認識を実装しません。職員が普段LINEで使っているのと同じ操作なので、教える必要がありません。

  • アプリが受け取るのは文字列だけです。音声データは自社サーバーにも外部APIにも送りません
  • Web Speech API は iOS Safari で連続認識が止まるため採用しません。対応ブラウザでは補助的に提供します
  • 音声入力は句読点が入らず口語になります。だからAI整形がセットで必要になります
  • 入力された生テキストは原文のまま保存し、整形結果と突き合わせられるようにします

「▶ 音声入力を再現する」を押すと、実際に話した内容が流し込まれる様子を確認できます。

同じ出来事でも、読む相手によって適切な書き方は違います。職員が3回書き分けるのは現実的ではありません。ここをAIが引き受けます。タブを切り替えて見比べてください。

  • 1回のAPI呼び出しで3文体を生成します。3回に分けると同じ入力トークンを3回払うことになります
  • 身体状況の事実は必ず文書にも書きます。そのうえで、説明が必要な事項には「お迎えの際に詳しくご説明します」という約束を添え、口頭連絡を送迎担当のタスクとして発行し、完了を記録します。「伝えたつもり」を仕組みで潰します
    ※当初は不安を与える事項を文書から外す設計でしたが、口頭連絡が漏れると何も伝わらないため、レビューを経て変更しました
  • 文書から外すのは他のご利用者の情報・未確定の推測・診断に類する記述の3つだけです
  • 「AIが補わなかったこと」も返させます。話に出ていない数値を勝手に埋めさせない仕組みです
  • 「昼ごはん半分」から主食5割が自動で選ばれます。非構造の話し言葉から構造化データを取り出す部分です
  • 保存前に必ず職員が確認します。AIの出力がそのまま確定することはありません

数値入力にキーボードを使わせません。水分量は ＋100 / ＋200 のボタンで加算します。手が濡れている状態で小さな数字キーを押すのは現実的ではありません。

  • 基準を外れた値は入力直後にその場で色が変わります（血圧142が該当）
  • 目標未達が続いている項目は、理由を添えて次の行動を促します
  • 未入力の項目は「0」ではなく「—」と表示します。測っていないことと、ゼロだったことは違います

各職員が音声で入力した記録から生成された handover_note を集約します。要注意の方を先頭に並べ替えます。

  • 入力を求めません。シフトに入る前に30秒で読み終わることだけを目指します
  • ここでもAI生成であることを明示し、確認した職員の記録を残します

片手操作のための設計原則

介護現場の制約から逆算した、この画面のルールです。

現場の制約画面設計での対応
片手しか空いていない
もう片方で利用者を支えている		主要操作をすべて画面下部3分の1に配置。上部は情報表示のみ
手袋・手が濡れているタップ領域は最小 44×44px。隣接要素との間隔を8px以上確保
立ったまま・移動中1つの記録を1画面で完結させ、画面遷移を挟まない
書く時間がない音声入力を起点にし、文章化はAIに任せる
屋外（送迎中）の明るい場所本文と背景のコントラスト比 4.5:1 以上を確保
この画面で説明したいこと。介護記録アプリの失敗は、たいてい「現場が入力してくれない」ことで起きます。入力項目を増やせば記録は詳しくなりますが、現場は使わなくなります。入力の負荷を下げたまま、出力の価値を上げる——音声入力とLLMの組み合わせは、そのトレードオフを崩せる数少ない手段です。だからこのアプリは、機能一覧ではなくこの1画面から設計しました。
